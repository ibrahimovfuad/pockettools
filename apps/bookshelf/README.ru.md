# Полка — трекер книг

Готовый сайт лежит в папке `public`. Собирать ничего не нужно.

## 1. Залить на Netlify
1. Открой app.netlify.com/drop и перетащи туда **папку `public`** (именно её, не весь архив).
2. В Site configuration → Change site name задай имя, например `polka-fuad` → адрес будет `polka-fuad.netlify.app`.
3. Обновлять потом: проект → Deploys → перетащить `public` в поле внизу страницы (не на /drop — так создастся новый сайт).

## 2. Firebase (проект тот же, login-e91f7)
1. Authentication → Settings → Authorized domains → Add domain → `polka-fuad.netlify.app`.
2. Firestore Database → Rules → заменить всё содержимым файла `../../firebase/firestore.rules` → Publish.
   В файле правила всех трёх приложений: настроение, привычки и полка.

## 3. Google Cloud (вход через Google)
console.cloud.google.com → проект login-e91f7 → APIs & Services → Credentials → Web client:
- Authorized JavaScript origins → `https://polka-fuad.netlify.app`
- Authorized redirect URIs → `https://polka-fuad.netlify.app/__/auth/handler`

Сохранить. Применяется за 5–10 минут.

## 4. На iPhone
Открыть сайт в Safari → Поделиться → На экран «Домой».

## Как быстро проставить даты 60+ книгам
1. Профиль → Экспорт → «Пустой шаблон» (или «Таблица CSV», если книги уже добавлены).
2. Заполнить в Numbers / Excel / Google Таблицах. Колонки: Название, Автор, Статус, Начал, Закончил, Оценка…
   Даты можно писать как `2023`, `2023-05`, `05.2023`, `12.05.2023`.
   Статус: `прочитано`, `читаю`, `хочу`, `бросил` (пустой + есть дата окончания = прочитано).
3. Сохранить как CSV → Профиль → Импорт из файла. Перед загрузкой покажет, что добавится и что обновится.
   Уже существующие книги не задублируются, у них обновятся только заполненные поля.
   Подходит и экспорт из Goodreads (CSV).

## Ссылка для друзей
Профиль → «Ссылка для просмотра». Друг открывает её без входа и видит полки, оценки и цитаты (их можно скрыть).
Изменить ничего не может. «Сменить ссылку» — старая перестаёт работать.

## Для разработки
`npm install && npm run build` собирает `src/main.js` в `public/app.js`.
Демо без входа: открыть сайт с `#demo` в конце адреса.
